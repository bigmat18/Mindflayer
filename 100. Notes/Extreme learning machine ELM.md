# Extreme learning machine ELM

It's a specific type of neural network of **Feedforward** type for **classification**, **regression**, **clustering**, **sparse approximation** with a single layer. These types of NN don't use backpropagation and it is also called **Single Hidden Layer Feedforward Network (SLFN)**.
