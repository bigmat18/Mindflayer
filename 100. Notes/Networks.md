# Network

**Networks** are suited to specify that there is some kind of relationship between two or more items
- Items in a network are called **nodes**. A **link** between two nodes is a relationship between two items
- Network nodes and links can have **attributes** associated

![[Pasted image 20251215145023.png | 550]]

### Trees
**Trees** are networks with a hierarchical structure and no cycles
- Each child node has exactly one parent node pointed to it
- **Examples**: organization chart of a company; evolutionary relationships between species in the biological tree of life (humans and monkey child nodes sharing the same parent node of primates)

![[Pasted image 20251215145109.png | 300]]

### Meshes
**3D meshes** are a particular type of graph used in Computer Graphics to represent 3D models
- Nodes are called **vertices**, arcs are called **edges**, and we also have polygons, called **faces**
