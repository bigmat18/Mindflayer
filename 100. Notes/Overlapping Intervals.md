# Overlapping Intervals

This pattern describes an efficient technique to deal with overlapping intervals. In a lot of problems involving intervals, we need:
- **to find overlapping intervals**: find the intersection between two set of intervals
- **merge intervals**: given a collections of intervals merge all overlapping intervals into ones
- **insert intervals**: add a new intervals in a list of intervals when it overlap
