# Radial bar Charts

Similar to a bar chart (same line marks used to encode a quantitative attribute with the length channel), the only difference being the radial versus rectilinear orientation of the axes

![[Pasted image 20251216154833.png]]

Re-ordering can help comparing the highest to the smallest values, which are adjacent. They would not be necessarily one next to the other in a classical bar chart.

![[Pasted image 20251216154913.png | 300]]

Radial bar charts can come in different forms:
- this form can help visualizing which category gets closer to the maximum value (given by the closure of the circle)
![[Pasted image 20251216154958.png | 250]]

- Radial bar charts can be revisited to encode multiple attributes
![[Pasted image 20251216155037.png | 300]]
