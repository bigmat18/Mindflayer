# Sunburst Charts

Radial layouts can also be used to visualize hierarchies. Sunburst charts visualize hierarchies (tree structures) with concentric circles
- each ring represents a level in the hierarchy, moving outwards

Multiple channels used:
- distance from the center represents levels in the hierarchy
- angle represents connections amongs items (nodes)
- color is used to give information about items (nodes)
