# Jacobian Matrix

In Calculus and, in particular, in vector calculus and infinity calculus, the Jacobi Matrix of a function $f$ that has domain and co-domain in a Euclidean Space is the matrix with elements first partials derivatives.

$f: U \subset \mathbb{R}² \to \mathbb{R}^m$ is a function defined in an open set $U \subset$ of Euclidean Space $\mathbb{R}^n$. The Jacobin matrix is the following matrix:
$$
Jf = \begin{bmatrix}\frac{\partial f}{\partial x_1} & \dots & \frac{\partial f_1}{\partial x_n} \\ \vdots & \ddots & \vdots \\ \frac{\partial f_m}{\partial x_1} & \dots & \frac{\partial f_m}{\partial x_n}{}\end{bmatrix}
$$
It is very useful because it the function $f$ is differentiable, the Jacobian represent the best linear approximation of $f$ near a givven point. This allow to extend the concept of derivates to vectors functions.
